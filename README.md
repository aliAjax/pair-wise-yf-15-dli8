# hxyfront-62003 法医昆虫样本追踪台

法医昆虫样本追踪前端工具，数据仅保存在浏览器 localStorage。预置 4 个案件与 6 份样本。

## 功能

- **入库登记**：录入容器条码、采样网格、环境温度、暴露阶段、虫种、发育阶段、保存方式、采样时刻。条码在库内重复或网格在案件内重合时，样本保留待核对，不能进入鉴定队列。
- **待核对**：核对人员补写现场照片编号后，样本才能归回案件、进入鉴定队列。
- **鉴定队列**：鉴定员按虫种与发育阶段筛选；详情抽屉可见全部字段、温度曲线、历次核对与封存副本；在队样本可封存。
- **案件关联**：按案件查看全部样本（含待核对、已封存、复检副本）。
- **封存与复检**：封存冻结记录与温度曲线；复检仅建立副本，原记录与温度曲线不动。

## 分层

- `src/domain/` 判定层：类型与规则（入库判定、状态门、队列筛选）
- `src/store/` 存取层：localStorage 读写、预置数据、动作门面
- `src/pages/`、`src/components/` 页面层：四个页面与详情/温度曲线组件

## 技术栈

React + Vite + TypeScript
